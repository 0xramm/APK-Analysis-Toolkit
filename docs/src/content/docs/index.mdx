## What it does

<CardGrid stagger>
	<Card title="App Manager" icon="list">
		Lists every installed package with no name-based filtering, with type-to-filter search everywhere a package is picked, plus detailed package info, install/uninstall/enable/disable/launch.
	</Card>
	<Card title="Rooted Sandbox" icon="rocket">
		Detects or creates a rootable (non–Play Store) Android emulator, roots/de-roots it on demand, and runs the whole setup with live progress — no silent multi-minute waits.
	</Card>
	<Card title="SSL Pinning Bypass" icon="approve-check">
		Pushes frida-server, bypasses pinning for a picked package via Frida's codeshare, and tracks active sessions so you can re-pin cleanly.
	</Card>
	<Card title="mitmproxy Interception" icon="magnifier">
		Starts mitmweb with a valid auth token (no more 403s), filters out connectivity-check noise, and installs its CA as a trusted system root — including the dm-verity reboot cycle most guides skip.
	</Card>
	<Card title="Malware-Style Triage" icon="warning">
		`Package info` automatically flags name/location impersonation, dangerous permission combos, placeholder versions, and verifies the real signing certificate — caught a fake "mParivahan" app posing as Google Play Services live, during development.
	</Card>
	<Card title="Static Analysis Tools" icon="open-book">
		A separate Static Analysis Setup menu auto-installs apktool and JADX on first use, decompiles a picked package straight from the device into the repo's own `workspace/` folder, and gets MT Manager onto the sandbox for on-device poking around.
	</Card>
</CardGrid>

## Why this exists

Setting up an Android pentest/malware-analysis sandbox usually means stitching together Android Studio, Frida, objection, and mitmproxy by hand from a dozen different guides — and re-learning the same gotchas every time (dm-verity reboot cycles, ambiguous multi-device `adb` sessions, mitmweb's token requirement). This toolkit automates the whole pipeline in one terminal UI, and documents every gotcha it had to work around along the way.
